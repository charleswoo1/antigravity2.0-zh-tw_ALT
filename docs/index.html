Google Antigravity 2.0 繁體中文（台灣）中文化工具

Antigravity 2.0 Traditional Chinese ALT 是非官方社群中文化工具，將支援版本的 Antigravity 介面套用為繁體中文（zh-TW），支援 Windows x64 與 macOS。

本專案與 Google / Antigravity 官方無關，不包含或散布官方 proprietary 二進位檔案。所有中文化修改都在使用者自己的電腦上完成。

下載 Google Antigravity 繁體中文版

目前 ALT 版本：1.4.0。明確支援 Antigravity 2.13.0、2.14.0、2.15.0、2.15.1、2.16.0、2.17.0。

Windows x64 繁體中文安裝程式 Windows x64 官方英文還原工具 macOS Apple Silicon（arm64） macOS Intel（x64）

Antigravity 中文化會翻譯哪些內容？

ALT 翻譯選單、設定、按鈕、導覽與一般操作介面；程式碼編輯器、Terminal 內容、Debug Console、輸入框與自動完成候選等開發內容則保留原文，避免影響複製、搜尋、比對文件與除錯。

支援 Windows 與 macOS

Windows x64 為正式驗證平台。macOS Apple Silicon（arm64）與 Intel（x64）已通過自動化 build、ad-hoc signing、ZIP 結構與 payload 驗證，目前仍屬公開先行版本。
